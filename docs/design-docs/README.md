# Campaign Studio — Design reference

The visual direction chosen before the UI was built: **Floating Conservatory**, with **Montserrat**. The theme tokens
in `frontend/src/style.css` follow [DESIGN.md](DESIGN.md). The wireframes guided the layout; the shipped UI has since
grown beyond them (strategy step, delivery page), so the application is the source of truth for behaviour.

| Frame | Purpose |
| --- | --- |
| [01 Brief](wireframes/01-brief.png) | First-use campaign input |
| [02 Proposals](wireframes/02-proposals.png) | Audience comparison |
| [03 Content](wireframes/03-content.png) | Editable channel content + preview |
| [04 Review](wireframes/04-review.png) | Final summary + confirmation state |

Each frame has an SVG beside its PNG; [wireframes/index.html](wireframes/index.html) is an offline gallery.
[reference/floating-conservatory.png](reference/floating-conservatory.png) sets material, palette and mood.
