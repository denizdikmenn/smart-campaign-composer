  looked at it in a browser; the typecheck and build pass and the running dev
  server compiles all three changed files.

  The four stages come from DESIGN.md, and together they cover the six steps in
  REQUIREMENTS.md:

  ┌───────────┬───────────────────────────────────┬────────────────────────┐
  │   Stage   │              Covers               │         State          │
  ├───────────┼───────────────────────────────────┼────────────────────────┤
  │ 1         │ Brief, AI suggestions, choosing   │ In progress, with live │
  │ Audience  │ an audience                       │  status                │
  ├───────────┼───────────────────────────────────┼────────────────────────┤
  │ 2 Content │ SMS and email drafts              │ Lock icon and "Coming  │
  │           │                                   │ soon"                  │
  ├───────────┼───────────────────────────────────┼────────────────────────┤
  │ 3 Review  │ Preview and approval              │ Lock icon and "Coming  │
  │           │                                   │ soon"                  │
  ├───────────┼───────────────────────────────────┼────────────────────────┤
  │ 4         │ Sending and monitoring            │ Lock icon and "Coming  │
  │ Delivery  │                                   │ soon"                  │
  └───────────┴───────────────────────────────────┴────────────────────────┘

  How it moves: a progress line runs along the four stages and fills smoothly as
  you work through the Audience stage. A short status under the current stage
  follows along:

  ┌─────────────────────────┬────────────────────────────────────┬──────────┐
  │         You've…         │            Status shown            │  Line    │
  │                         │                                    │   fill   │
  ├─────────────────────────┼────────────────────────────────────┼──────────┤
  │ Not generated yet       │ Describe your campaign             │ 15%      │
  ├─────────────────────────┼────────────────────────────────────┼──────────┤
  │ Got audience options    │ Compare options                    │ 50%      │
  ├─────────────────────────┼────────────────────────────────────┼──────────┤
  │ Picked one              │ Confirm your choice                │ 75%      │
  ├─────────────────────────┼────────────────────────────────────┼──────────┤
  │ Clicked "Use this       │ Audience set (stage 1 gets a check │ 100%     │
  │ audience"               │  mark)                             │          │
  └─────────────────────────┴────────────────────────────────────┴──────────┘

  If you regenerate, it drops back to "Compare options". A brief that only gets
  a clarifying question, or no usable audience, stays at "Describe".

  Look and behaviour:
  - Position: the bar stays at the top of the screen as you scroll, on the
    frosted background DESIGN.md allows for top bars.
  - Stage circles: the current stage has a pistachio circle that pulses once. A
    finished stage turns solid forest green with a check mark.
  - Narrow screens: it shrinks to one line ("Step 1 of 4 · Audience · Compare
    options") above the progress line and circles.
  - Accessibility:
    - It's marked up as a progress list with the current stage flagged.
    - Screen readers hear "(completed)", "(current: Compare options)" or "(not
      available yet)".
    - Locked stages can't be clicked, as DESIGN.md requires for anything not
      built yet.
  - Header: the old "Step 1 of 4 · Audience" text is gone, since the indicator
    now shows that.

  The changes are in StepIndicator.vue
  (frontend/src/components/StepIndicator.vue), NewCampaignView.vue
  (frontend/src/views/NewCampaignView.vue), and BriefComposer.vue
  (frontend/src/components/BriefComposer.vue), which now tells the page when
  results arrive.

  1. Variant or group (outer box). Each A/B variant gets its own box, headed

     Behavioral groups are shown by group name. A plain campaign is headed

     stay the same. If a card has only one language, its name is shown as plain
     text instead of a toggle.

  "Message previews (12)" to something like "Message previews · 2 variants ·

  - Missing languages: the server returns at most 12 sample messages. A campaign
    with many variants, groups and languages can therefore have cards that lack
    some languages. Those cards simply offer fewer language options.
